## 🚀 النشر على Vercel | Deploy to Vercel

### One-Click Deploy

1. احفظ الملفات في مستودع GitHub
2. ادخل [vercel.com/new](https://vercel.com/new)
3. اختر المستودع
4. اضغط **Deploy** ✅

### أو عبر CLI

```bash
npm i -g vercel
vercel login
vercel --prod
```

## ⚙️ التشغيل المحلي | Local Development
